# Pitch Bullao · 60–90 segundos

Bullao: menos bulla, cuentas claras. Imagina el cierre de mes: llega la factura normal de un proveedor conocido. En vez de perseguir correos y hojas, envías el documento al asistente compatible que ya usas. Bullao contrasta la evidencia con los acuerdos y la política autorizada; si todo cuadra, queda lista para simulación y revisión, sin pedirte una confirmación rutinaria por cada cuenta.

Ahora llega la misma factura dos veces. Bullao detecta el duplicado y la frena: no reserva otra vez ni deja que la factura cambie las reglas. Después aparece una excepción: “solo esta vez”. No se convierte silenciosamente en permiso permanente; Bullao lleva la decisión a una persona por el flujo autenticado existente.

El asistente conversa; Bullao aporta el motor determinista, evidencia y registro. La web conserva la auditoría y las autorizaciones. Ver demo abre una sesión local con datos ficticios y política precargada: no es una integración de asistente ya conectada ni mueve dinero real. Para conectar, configura un cliente MCP remoto con la URL de tu instancia (`${origin}/mcp`) y accede con tu propia cuenta mediante OAuth. Compatibilidad documentada no equivale a conexión probada. El runtime debe poder leer el documento: Bullao no promete OCR universal ni conectores de correo o WhatsApp.
